如何解读：

  • Image Precision (IP@3)：MSMO 标准，|Top-3 命中 GT| / 3 — 推荐精确率，Stage-3 输入质量。
  • Image Recall (IR@3)：MSMO 标准，|Top-3 命中 GT| / |GT| — GT 覆盖率，Stage-3 可挽救上限（GT 未进 Top-3 则 VLM 无法补回）。
  • R-Precision：取 Top-|GT| 的 recall 式指标；|GT|>3 时比 IR@3 多看更深层候选。
  • Exact-match 指标（Jaccard@3、MAP、MRR）衡量排序与 ID 命中。
  • MaxSim@3 是软视觉相似度，高 MaxSim + 低 Jaccard 可能意味着「视觉相似但未 exact match」。
  • 若 Proposed 在 exact-match 上不占优但 MaxSim 接近，可关注布局/共现模块是否拉高了语义相关但 ID 不同的图。
