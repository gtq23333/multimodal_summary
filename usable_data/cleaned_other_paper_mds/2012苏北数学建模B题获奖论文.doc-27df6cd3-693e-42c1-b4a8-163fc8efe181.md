企业的生产调度与销售问题是许多企业所面临的问题，也是企业达到利润最大化所必需解决的问题。本文就是针对煤炭企业生产最优化配比问题，在第一问中根据给出的条件运用线性规划的方法对煤炭企业的生产给出了最优的配置方案。在第二问中是在同时放入料时对筒仓内部产品的分布与堆积情况，运用数值模拟法得出筒仓内部流态物质在不同位置处流速不同，进而运用Janssen理论计算值计算出筒仓内部不同状态时的流体速度，再进一步运用数学模型与图形分析得出筒仓内部产品在任一时刻的分布与堆积情况。通过建立函数和编写程序的方式对产品入放料过程中仓内产品的分布与堆积情况进行实时模拟，对给定的时间，可快捷方便的得出仓内产品的分布与堆积情况，进而实现准确有效的产品入仓和混配装车。

根据Janssen公式：  $\frac{w}{\rho} = \lambda D_{0}$  其中  $\rho$  为粉体密度，  $\lambda$  为粉粒特性(粒径、内摩擦系数、内压力等)有关的常数，常数n在  $2.5\sim 3.0$  之间取值，据为大多数  $n = 2.7$  ，  $D_{0}$  为出料口径向径。其中参数值根据实际给出固定值，故出料口两种速度可设为  $w_{1}$  ，  $w_{2}$  （即认为已知），在一次连续生产中第i种原料生产的产品放入同一筒仓的时间为  $t_{i}$  ，最优停歇时间均为  $t_{0}$  以i种产品的一次生产为一个周期T，入料口速度为  $v_{\lambda}$  ，仓内产品高度为H/2时，仓内产品量为  $m_{\#} = \rho \mathrm{v}_{\#}$  （  $\mathrm{v}_{\#}$  为高度为H/2处的体积），  $\mathrm{v}_{\#} = \frac{1}{8}\pi D^3 H - \frac{D^3}{12}\pi \tan \alpha_{\circ}$

第一种原料生产时：在刚开始时仓内产品高度低于H/2，故产品是管状流动，时间t内，  $\triangle \mathbf{v} = \nu_{\lambda} - \nu_{2}$  。达到H/2高度时所需要的时间为：  $t_{\#} = m_{\#} / \triangle \mathbf{v}$  ，当  $t< t_{\#}$  时，仓内只有管状流动状态，  $\triangle \mathsf{m} = t_{1}$ $\left(\nu_{\lambda} - \nu_{2}\right)$  ；当  $t_1 > t_{\#}$  时，仓内就会是管状流动状态和整体流动状态，  $\triangle \mathsf{m} = \left(t_{1} - t_{\#}\right)$ $\left(\nu_{\lambda} - \nu_{1}\right) + m_{\#}$  ；在停车后，设出料速度为匀速：q（由实际给出），此时仓内剩余量：  $m_{\# \parallel 1} = \triangle \mathsf{m} - \mathsf{q}t_{0}$

第二种原料生产时：

$m_{\# \parallel 1} > m_{\#}$  时：  $\triangle \mathsf{m} = m_{\# \parallel 1} + t_{2}w_{1}$

# 七、模型评价

对本题我队建立了两个模型，一是理想筒仓在同时放入料时内部产品分布模型，二是对于多个入料口和多个放料口类型筒仓的产品入放料过程中仓内产品的分布与堆积情况模型。

对于模型一，其利用线性规划，虽然对于主观与客观的因素分析不到位，但其对问题进行分析得出主要影响因素，具有可重复性、易操作性、易判断性、等优点。

对于第二个模型，虽然其带有一定的主观性，但它是基于层次分析法，因此其主观性是不容易消除的，但其具有全面把握性和易判断性等特点。
