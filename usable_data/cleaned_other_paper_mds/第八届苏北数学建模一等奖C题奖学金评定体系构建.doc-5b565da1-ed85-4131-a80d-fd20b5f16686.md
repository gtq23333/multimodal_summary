一，综合成绩的合理计算方法

因为各门课程的重要程度和学习量大小不同，

为了体现这种重要程度，通常采用加权平局的方法计算平均成绩．综合成绩的计算过程如下：

1. 考试课平均成绩计算方法：第  $j$  位学生的考试课加权平均成绩  $A_{j} = \frac{\sum_{i = 1}^{6}x_{i}a_{i}}{\sum_{i = 1}^{6}a_{i}}$

其中，  $x_{i}$  表示第  $i$  门考试课的学分，  $a_{i}$  表示第  $i$  门考试课的卷面得分

2. 考查课平均成绩计算方法：第  $j$  位学生的考查课加权平均成绩  $B_{j} = \frac{\sum_{i = 1}^{6}y_{i}r_{ji}}{\sum_{i = 1}^{6}y_{i}}\times 100$  其中，  $y_{i}$  表示第  $i$  门考查课的学分，  $r_{ji}$  表示第  $j$  个学生第  $i$  门考查课的量化得分

3. 综合成绩计算方法：我们利用高校普遍采用的公式计算综合成绩：

第  $j$  位学生的综合成绩为  $C_{j} = \alpha A_{j} + (1 - \alpha)B_{j}$  其中，  $\alpha = 0.7$ ，  $A_{j}$  为第  $j$  位学生的考试课加权平均成绩，  $B_{j}$  为第  $j$  位学生的考查课加权平均成绩，通过以上三步我们可以得到综合成绩的分数和具体排名
