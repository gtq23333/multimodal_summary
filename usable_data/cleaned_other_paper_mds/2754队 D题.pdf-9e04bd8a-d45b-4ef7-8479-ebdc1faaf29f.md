# 四、模型的建立与求解

# 4.1问题一

在NBA设定的原有规则上，在不更改原有规则的前提下，通过增加四分线来增加比赛的观赏性。在实际情况中，球员的投球区域与投球命中率是不可忽视的因素之一，还要结合不同球员之间身体素质以及能力的不相同，制定的四分线规则将需要确定约束条件，如肯道·马绍尔、贾马尔·克劳福德、斯蒂芬·库里等人的远投能力比一般球员的都要强。他们的命中率也相对高很多，而对于这种远投能力强的球员，可以采用四分线仅用于加时赛与全明星赛中使用。本文综合现在NBA中各个球员状况与投球距离相对应的投球命中率做出分析，从而建立出模型。

由题目所给出的NBA三分线确定过程以及各个年代的不同改动，我们通过网络，找到历年NBA比赛中，随机抽取五十名球员的五年间得分具体状况，建立表格，计算出三分真实投球命中率记为α，二分真实投球命中率记为β，根据NBA标准篮球场的尺寸，计算出三分线内面积（即二分球所占区域）为am²，三分线外至中场线所包含面积（即三分球所占区域）为bm²，建立函数满足（a，β）、（b，α）两点，再代入四分球真实命中率y，得出四分球所占面积为Dm²，再根据NBA场地的对称性来规划场地范围。四分线模拟三分线规划制度，以篮筐为中心，以x为半径，画一个圆弧，在圆弧内至三分线的区域则为三分球区域，四分线外至中场线则为四分球区域。

# 4.1.1四分线的确定需要满足情况以及四分线确立所需条件

NBA比赛中，四分线的推出，将在不影响比赛的公平性的前提下还要增加比赛的观赏性，所以，需要满足以下条件：

1）四分线的推出，不能破坏现有的NBA所有规则。2）四分线的推出，不能更改NBA现有的场地范围大小。3）四分线的推出，符合NBA比赛中相对平衡性。4）四分线的范围，应在28英尺-32英尺范围之内。

# 4.1.2真实投篮命中率的描述

投篮命中率是衡量一名篮球球员得分能力的重要标志，它由投篮命中率、三分球命中率

和罚球命中率组成。计算公式为投篮命中率  $\coloneqq$  全场投中次数/全场出手次数。

三分球真实投篮命中率则为：三分球投篮命中率  $\coloneqq$  全场三分球投中次数/全场三分出手次数。

二分球真实投篮命中率则为：二分球投篮命中率  $\coloneqq$  全场二分球投中次数/全场二分出手次数。

由问题一中所得出的数学模型，代入四分球的真实投篮命中率0.2464240625，得出四分球区域面积为127.772757295933m²。

根据NBA场地是出于对称性的特点。三分线确定是采用一个半圆加一个长方形的方法，所以四分线也采用同样方法。三分线的半圆采用136°，四分线也采用136°。则列出四分线区域面积：

设四分线所画圆弧半径为  $\epsilon$  。角度为  $\theta^{\circ}$  。则四分线内区域面积为

$$
(\epsilon^{2})\pi *\frac{\theta^{\circ}}{360^{\circ}} +2500*\left(400 + \epsilon *\cos \frac{\theta}{2}\right) = 127.7725757295933 \tag{5}
$$

因为三分球运用的圆弧角度为136°，所以四分球也同样运用相同圆弧角度。即  $\theta = 136^{\circ}$  。代入上面公式中，求出半径为27.0128英尺，换算为米，为8.234111米。即，四分线应该建立在离边线27.0128+4.5=31.5128英尺。

# 五 模型的评价与推广

优点：

（1）在数据处理方面，我们详细的分析了NBA球员2015-2016年每场比赛的投球率、命中率、三分投球率、失误率，并以表格形式反映出来。规范了数据的格式和可用性，为下一步解题提供了简洁的数据资料。

（2）模型在图像处理和显示上，我们采用了MATLAB、CAD、EXCEL、LINGO作图，拟合数据的变化趋势，使问题的结果更加的直观。

（3）在模型的建立上，我们省去了无用的模型，使模型更加的贴近“用最简单的方法解决最难问题”的建模思想。

（4）在第一问中，我们充分的考虑了NBA现今球员与以往球员身体素质的不断提高，所带来的激烈性的降低，同时也兼顾了NBA的盈利问题，较为全面的解决了因四分线的提出而影响NBA盈利的问题。

缺点：

（1）在计算过程中，有些值采用平均值，所以会存在有一定的误差。但误差较小，计算出来的值可以使用。

（2）在模型的建立过程中，忽略了些许因素，结果适用的情况比较局限性。

（3）在实际状况中，总会有几个天才球员，对结果具有一定影响力，但波动范围不是很大。

推广：

本模型运用基本的数学模型，建立区域面积与命中率关系，且适用投球效率才推算出四分球真实命中率，数据使用合理，适用于一般情况，但由于实际情况，推荐四分线只适用于全明星赛与任何NBA比赛的加时赛中。
