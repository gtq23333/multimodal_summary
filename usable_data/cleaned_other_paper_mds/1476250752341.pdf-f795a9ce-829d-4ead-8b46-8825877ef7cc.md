布袋除尘器作为烧垃圾烟气处理方面的高效除尘设备备受关注，然而长时间稳定运行能力的乏限制其进一步推广和普及。本文通过建立数学模型量化分析袋式除尘器的稳定性并预测垃圾烧厂的最大扩建规模、使用新工艺以后的稳定性能的提升情况，最后给环保部门的检测提供相关建议。

本文首先将袋式除尘器的稳定性定义为其在一个时间周期内除尘效率的变异系数。其次，本文依次分析可能会对袋式除尘系统除尘效率产生影响的各因素并分析其对除尘效率的影响随时间的变化，这些因素包括：持续影响除尘效率的蠕变及磨损，直接影响除尘效率的温度以及通过布袋破损率间接影响除尘效率的烟温、压差、含湿量等因素。考虑到上述各因素可以看作相互独立，本文由此可以得到袋式除尘器在正常运行状态下除尘效率随时间的变化情况。在此基础上，本文利用实际运行过程中除尘效率的数据进行拟合，验证上述除尘效率随时间变化曲线的合理性，并对其运行稳定性作出评价。

针对问题一，本文建立高斯扩散模型，分析在距离垃圾烧厂一定距离内的各处烟尘浓度的分布情况，同时结合相关标准以及排放总量等相关约束得到烟尘排放浓度的上限。与此同时，针对除尘效率的波动，本文分析了其对经济及技术原因的敏感性，并在此基础上利用相关数据，计算在保证盈利的情况下垃圾烧厂通过提高布袋更换频率等方式对除尘效率提高的最大限度，最终得到在满足排放标准的前提下，垃圾烧厂的最大扩建上限。

针对问题二，本文在原除尘效率随时间变化函数的基础上引入一个白噪声来刻画其他因素对除尘效率影响的随机效果，以此对实际运行过程中除尘效率的动态变化情况进行预测。另外，本文将上述结果与新型除尘工艺的除尘效率的稳定性进行比较，得到换用新型工艺后袋式除尘器稳定性的提高情况。

1.1 研究背景及意义现今，焚烧处理生活垃圾的方式是中国维持可持续发展的必由之路，然而由此带来的排放污染问题却引发公众担忧。袋式除尘技术作为一种有效净化含尘烟气的技术，近几年在我国政府和相关政策的支持下应用日益广泛。根据袋式除尘系统稳定性确定焚烧垃圾厂扩建上限并预测新型超净除尘代替工艺系统持续稳定性的提升量将对该问题的有效解决产生积极影响。本文针对袋式除尘系统稳定性构建有效的数学模型量化分析袋式除尘系统运行稳定性问题。

# 1.2国内外研究现状

袋式除尘器本体巨大，工作情况非常复杂，给控制系统带来很多扰动，是一个非线性、时变、存在变量耦合的控制对象，这一点已经在谷艳玲的研究中被有力的论证了。不仅如此，袋式除尘器的运行工况的变动会引

起参数变动，过滤效率又受到很多因素的制约。许世森[2]首次提出了温度与捕集比的理论关系式并利用移动颗粒层在高温状态下进行过滤除尘的实验结果进行验证。周军[3]分析了各因素单独变化对过滤效率的影响，并结合实验数据验证了不同过滤阶段存在临界过滤速度的存在。

出于对袋式除尘器时变性的考虑，该控制系统明显需要具有很好的鲁棒性，如何刻画和仿真模拟其工作过程则成为了研究热点。当前研究成果中，很少有学者文献建立明确的数学模型来描述高温烟气袋式除尘器，有关袋式除尘器控制模型和仿真的研究也处于起步阶段。陈硕[4]介绍了静电布袋复合除尘器的结构原理和优势并借助计算流体力学（CFD）对除尘单元的冷态流场进行数值模拟，发现除尘器入口进风箱处设置气流分布板可以迫使气流重新分配，改善流场分布的均匀性。于兴鲁[5]将理论、实验和模拟三种方法相结合来研究除尘机理和除尘效率的关系，并借助三维建模软件实现了除尘效率对主要因素的数值模拟。王丹丹等人[6]借助计算流体动力学（CFD）方法建立袋式除尘器清灰数值计算模型来

模拟清灰时的压力峰值分布。

过滤除尘是使含尘气流通过过滤材料而将粉尘与烟气分离。过滤除尘的除尘效率可高达  $99\%$  。袋式除尘器除尘效率高，捕获粉尘颗粒粒径可达亚微米级，便于直接回收干料。除尘器的关键元件是滤袋，而保证滤袋除尘效率的关键是滤料，目前国内外主要采用聚四氟乙烯覆膜滤料，这种滤料耐高温，除尘效率高，使用寿命长。陈碧波[7]制定了聚四氟乙烯（PTFE）复合材料压缩蠕变的两种测试方法分别来判断其蠕变性能的优劣和定量计算蠕变过程中的状态参数，另外通过分析其蠕变机理建立了相应的蠕变力学模型和压缩蠕变方程并得到了曲线拟合结果。王伟莎[8]对聚四氟乙烯（PTFE）作为高温过滤材料的蠕变性能进行研究，通过分析常温实验的数据建立了相应的六元件并联模型。

另外，针对滤料破损及其对过滤效率产生的影响，一些学者已经对其发生机理给出了相应解释。丁炜以东北某电厂的机组除尘器实际运行工况为实例，研究滤料损坏形式以及相应原因。王振华[10]对不同织物构造形式的袋式除尘滤料进行过滤效率研究，同时将量纲分析理论和模糊灰色理论引入滤料理论过滤效率的建模之中，形成了一套行之有效的评价体系。聂换换[11]分析了滤料出现磨损破洞、袋身腐蚀、滤袋被高温粒子烫穿和滤袋下被烧断等现象的原因进行分析，研制出四种不同的超细玻璃纤维针刺复合滤料进行试验，发现在相同测试条件下不同滤料会产生不同过滤特性，实现一定经济价值。

# 1.3研究目标及思路

本文以传统的袋式除尘系统为研究对象，定义其系统稳定性合理指标，规定进入袋式除尘器的烟气浓度作为系统输入量，排出袋式除尘器的烟尘浓度作为系统的输出量。将袋式除尘系统的稳定性定义为其一年内在正常工作状态下除尘效率的变异系数（标准差/平均值），用以衡量各观测值变异程度的一个统计量同时消除单位和平均数不同对两个或多个变异程度比较的影响。

由于兴鲁[5]、王丹丹等[6]和丁炜[9]可知，布袋蠕变、磨损状况，布袋破损率及输入端的平均烟温、压降、含湿量等均会构成影响袋式除尘系统除尘效率的因素，本文将其分为三类，一类是包含蠕变及磨损两个因素的持续影响因素类；

一类是温度等直接影响除尘效率的直接影响因素类；还有一类是由烟温、含湿量、压降等导致的布袋破损进而影响除尘效率的间接影响因素类。本文分别构建除尘效率持续影响机理模型和温度- 除尘效率直接影响模型以及布袋破损间接影响除尘效率模型来刻画上述因素与输出量的动态变化关系。然后，在环保标准、系统潜在不稳定性、故障排放时间限制等约束条件下，构建高斯扩散模型，求得垃圾焚烧厂在当前环保标准下的扩建上限，同时，本文给出环境保护综合检测建议方案。最后，将新型除尘工艺系统的各项参数指标导入袋式除尘器稳定性模型，实现对其持续稳定性能提升量的预测。

在模型一（除尘效率持续影响机理模型）中，只考虑布袋蠕变、磨损两因素对除尘效率的影响，利用量纲分析原理分别建立蠕变影响除尘效率模型及磨损影响除尘效率模型，求得蠕变、磨损两因素各自的除尘效率- 时间函数，最终得到在持续影响因素下的除尘效率- 时间函数。

在模型二（温度- 除尘效率直接影响模型）中，主要考虑温度因素对过滤过程中气体扩散沉积、惯性碰撞两部分的影响，分别构建两者的系统动力模型并假设两者相互独立，得到温度直接影响除尘效率的公式。

在模型三（布袋破损间接影响除尘效率模型）中，假设输入端的平均烟温、压强、含湿量等会对袋式除尘器除尘效率产生影响的因素保持不变，且不考虑其蠕变、磨损等情况，在输出量只与布袋破损有关的情况下，借助Abhilash Sasidharan，Siddharth Swaroop.etc[12]的最新成果，根据仿生学原理得到破损率和除尘效率关系的Sigemoid理论模型曲线，运用GLS（广义最小二乘法）求解参数，得到布袋破损率和除尘效率满足的公式。

由于三类影响除尘效率的因素可视为相互独立且共同影响布袋除尘器效率，本文根据上述模型求出的三类因素各自同除尘效率的关系式或对除尘效率影响的时变关系，得到除尘效率随时间变化的动态关系，从而得到用于衡量布袋除尘器的稳定性的变异系数。

本文通过量化分析布袋除尘器运行稳定性问题得到焚烧垃圾厂扩建上限并给出新型超净除尘代替工艺系统持续稳定性的有效提升量的预测值，深入揭示现行垃圾焚烧烟气处理技术缺陷以期促进除尘技术进步，同时也希望本文能对优化焚烧工况控制及运行维护规程有所帮助。

# 2 问题描述及分析

# 2.1 问题描述

综合研究现行垃圾焚烧发电厂袋式除尘系统影响烟尘排放量的各项因素，构建数学模型分析袋式除尘系统运行稳定性问题，并分析其运行稳定性对周边环境烟尘排放总量的影响。基于该模型回答下述问题：

- 同时将给定的焚烧厂周边范围单位面积排放总量限额（地区总量/地区面积）和垃圾焚烧厂扩建过程中系统潜在不稳定性作为约束条件，分析讨论焚烧厂扩建规模的环境允许上限是多少？并基于该分析结果，向政府提出环境保护综合监测建议方案；- 在除尘系统能够完全稳定运行且不考虑布袋破损对除尘效率影响的情况下，只改变输入端条件，预测在不同状态下输出量的变化，从而得到新型超净除尘代替工艺系统稳定性能的提升量。

# 2.2 问题分析

针对问题一，通过运动学微分方程刻画蠕变、磨损对除尘效率产生影响的物理过程构建模型一（除尘效率持续影响机理模型），从而得到蠕变、磨损对对除尘效率的持续影响；通过分别研究温度对惯性碰撞、气体扩散沉积的物理过程来建立模型二（温度- 除尘效率直接影响模型），进而得到温度对除尘效率的综合影响；另外，将检测数据、报表数据导入模型三（布袋破损间接影响除尘效率模型），得到平均烟温、含湿量、压降等影响布袋破损的因素对除尘效率的间接影响。由于三者共同决定了袋式除尘系统的稳定性，本文在假设各因素相互独立影响除尘效率的础上得到除尘效率与运行时间、运行温度的关系。最后本文构建模型四（高斯扩散模型），根据焚烧式垃圾处理场环保排放标准和空气质量标准确定一年当中不同时间里，垃圾处理厂最大焚烧上限，根据当前垃圾处理厂实际生产数据确定其在当前环保标准下的扩建上限，并由此本文给出环境保护综合检测建议方案。

# 4 模型——除尘效率持续影响机理模型

# 4.1 模型假设

- 保持袋式除尘系统输入端的平均烟温、压强、含湿量等条件不变。- 布袋破损达到更换标准后对除尘效率的影响不考虑。- 袋式除尘系统运行中布袋处于恒温且外界载荷不变情况下。

# 4.2 数据处理及分析

# 4.2.1 蠕变的概念

蠕变指的是材料在恒温、恒应力（外界载荷不变）的情况下，材料变形程度随时间增加的现象。蠕变不仅出现在塑料（高分子材料中），还出现在金属材料中。聚合物的形变是其特有粘弹性的突出表现，不仅与材料自身的凝聚态结构有关，而且受外力、温度影响显著，是高聚物一种典型的松弛过程，其实质是材料在一定条件下，内部各运动单元对外力作用的协同响应。

# 4.2.2 蠕变的影响因素

# a．温度

a. 温度随温度的升高，高聚物的分子热运动加快，热运动能量和自由体积都增加，各运动单元的松弛时间缩短，蠕变过程的推迟时间缩短，从而蠕变柔量随时间的发展加快。

# b．应力和应变

b. 应力和应变当高聚物所受的恒定应力低于其断裂强度时，它在任一时刻的蠕变柔量与作用力的大小无关。当应力较小时，链段运动的松弛时间较长，在较短时间周期内很难观察到由此引起的高弹形变。当应力较大时，分子运动的位垒降低，分子运动的松弛时间缩短，从而使得一些在低应力作用下本不可能实现的分子运动在大应力作用下得以实现，以至于在相同的观察时间内可表现出高弹形变强迫高弹形变，使蠕变柔量大大增加。

# c．流体静压力

c．流体静压力高聚物所受的流体静压力越高，自由体积就越小，各重分子运动单元运动的松弛时间越长。高聚物的蠕变速率因此降低。在一定观察时间达到的蠕变柔量减少，而应力松弛模量增高。

# d．热处理

d．热处理一般来说，将结晶聚合物在退火温度（Tm）以下或将非晶态高聚物在玻璃化温度（Tg）以下进行退火处理，可以降低蠕变速率。退火处理至少有三种作用一是消除高聚物内的残余应力；二是提高部分结晶高聚物的结晶度；三是促进非晶态高聚物包括部分结晶高聚物中的非晶相的体积松弛，减少自由体积。第三种作用也称作物理老化。[7]

以上四种因素为主要对蠕变产生影响的外部因素，而在袋式除尘器中，流速基本保持恒定，流体静压力的变化在极小范围内波动，于是此处忽略流体静压力对布袋滤料蠕变的影响。另外，布袋滤料在使用前均会统一进行退火处理，故本文不考虑热处理对于布袋蠕变产生的影响。而对于应力和应变，在袋式除尘器的运行过程中，只有极少数布袋会受到大于其断裂强度的应力并造成布袋断裂，而当布袋受到的应力小于其断裂强度时，应力对蠕变实际上没有影响。因此为了研究布袋滤料的蠕变情况随时间的变化，只考虑在恒定温度下滤料的应变量。至于温度对于滤袋过滤效率的影响，在之后的模型二中单独讨论。

# 4.2.3 滤料（PTFE）的蠕变机理及过程分析

# a．蠕变机理

PTFE是一种线形高分子，其蠕变过程实质上是由键长键角的变化引起的普弹形变、链段运动引起的高弹形变和高分子链重心迁移引起的翻性流动形变过程的线性叠加。

当PTFE材料受到一定载荷时，其键长键角首先产生形变，这是普弹形变，可回复；然后链段的运动产生高弹形变，部分可回复；接着是无定形区的分子链沿应力取向产生轻微滑移，这部分看作是勃性流动，无法回复，形成永久变形。PTFE更容易产生分子滑移，即永久变形，故更易蠕变。如果受到更大的恒定压缩载荷，结晶区的分子链也开始产生滑移，直至形成裂纹以至于发生破裂。

# b．蠕变过程

材料蠕变行为一般可以由压缩蠕变曲线图4.1进行研究判断，蠕变曲线上任意一点的斜率，表示该点的蠕变速率，按照蠕变速率的变化情况，可将蠕变过程分为三个阶段，如下图所示：

第I阶段是指瞬时应变  $\epsilon_0$  以后的形变阶段，这一阶段开始时会因为滤料突然接触到较高温度而膨胀，蠕变速率很大；随着时间的延长，蠕变速率逐渐减小，该阶段通常称为减速蠕变阶段，又称为过渡蠕变阶段。

第Ⅱ阶段通常称之为恒速蠕变阶段，又称为稳态蠕变阶段。这一阶段的特点是蠕变速率几乎保持不变，说明形变硬化与软化过程相平衡。一般所指材料的蠕变速率，便是以这一阶段的蠕变速率表示的，这一阶段的蠕变速率最小。

第III阶段蠕变速率会因为滤料老化等原因随时间增长又开始增加，有些材料最终会导致断裂。这一阶段被称之为加速蠕变阶段。[13]

综上所述，蠕变对滤料造成的影响主要是一个长期的过程，对于滤料的主要影响方式是通过形变，造成原始滤料的伸长，使得履带孔径的大小增加，从而除尘效率降低。下面本文重点研究蠕变随时间对过滤效率造成的影响。

# 4.2.4蠕变与过滤效率的关系

4.2.4 蠕变与过滤效率的关系通过上述关于蠕变机理的分析，可以看到布袋蠕变主要通过增加布袋孔径影响布袋的除尘效率，故该部分的重点在于分别找出过滤效率与滤袋孔径之间的关系，以及蠕变所造成的布袋孔径变化与时间的关系，最后将两者结合，得到过滤效率在蠕变的影响下与时间的关系。

# 4.2.6滤料（PTFE）的摩擦磨损机理

复合材料磨损的种类有很多，通用的分类方法是J.T.Burwell和C.D.Strange所提出的按材料的磨损基本形式分为：粘着磨损、磨粒磨损、疲劳磨损、腐蚀磨损，此外还有划伤及微动磨损等[14]。这几种磨损形式只是几种基

本磨损形式，而在实际袋式除尘器工作中所表现出的磨损通常不能纳入某一种形式，许多磨损现象都是基本类型的转化或复合。

PTFE分子链结构是  $\mathrm{C_2F_2}$ ，其中C、C原子以及C、F原子之间以共价键结合，具有较大结合能，因此分子内结合较牢固。PTFE分子之间靠范德华力相结合，大分子间引力小，因此结合力较弱。相比之下PTFE分子链不易断裂和分解，而大分子较易解脱与滑移。PTFE的分子结构决定了它的摩擦行为，但它的摩擦行为还受到其他因素的影响。

PTFE的磨损机理主要分以下几种：

# a.粘着磨损

摩擦表面静接触时，接触区域两表面粘接在一起。摩擦时，粘接点被剪切，导致一方材料损失的现象。同时表面上微凸峰在摩擦过程中相互碰撞，局部过热形成冷焊点，冷焊点受剪切时，较软材料上的微凸峰脱离基体。当高分子材料与金属对磨，局部过热面上的高分子材料粘附于金属表面，产生粘着磨损。

# b.磨粒磨损

当含有固体颗粒的流体，以与固体表面接近平行的状态与固体表面相对运动时，对固体表面造成的磨损叫磨粒侵蚀。

# c.疲劳磨损

疲劳磨损是指摩擦时表面受到周期性的交变载荷，表面上部分微凸体相互作用，使接触区域产生很大的变形和应力，在表层和亚表层形成裂纹而导致材料损失或破坏的现象。

# d.蠕变磨损

高分子材料是种粘弹性材料，所谓粘弹性，就是同时具有类似于粘性液体和纯弹性固体两者的性质。因而高分子材料在恒定外力持续作用下，形变会随时间推移逐渐增加，从而发生蠕变现象，根据外力的类型，可以有弯曲蠕变、扭转蠕变、拉伸蠕变及压缩蠕变等。

# e.微观破坏磨损

在正常相互摩擦过程中，细小颗粒的磨去可能导致撕落、划伤、犁耕等。

# 4.2.7PTFE基复合材料摩擦磨损研究现状

材料的摩擦磨损是复杂的动态过程，涉及摩擦磨损系统中的外部因素和材料的内部因素。外部因素指载荷、滑动速度和时间、环境温度、介质、表面粗糙度、对磨材质等；内部因素主要指材料的成分、组织结构和组分的物理化学性质及力学性能等。王家序、陈战[15]等人研究PTFE/石墨/玻璃纤维古河材料的摩擦学性能时发现，复合材料的摩擦系数、磨损率随滑动速度增大，呈先减后增现象。Yu.M.Pleskachevsky0[16]等人研究得出，PTFE的摩擦系数对温度有很大依赖，随滑动速度增加，材料的接触表面温度上升，摩擦系数下降，当摩擦生热使温度达到一定值后，温度继续上升会导致摩擦系数上升。H.Una[17]等人对PTFE复合材料的研究发现，PTFE的摩擦系数和磨损率均受滑动速度和载荷影响，随载荷增加，摩擦系数下降。

人们对影响复合材料摩擦学性能的内部因素也进行了一些研究。

综上所述，关于PTFE复合材料摩擦学性能，国内外学者以进行了大量研究，并取得了许多成果。PTFE复合材料的摩擦磨损是涉及摩擦系统中外部条件和材料内部因素的复杂过程，目前关于其磨损性能的研究大多以特定试验条件为主。

# 4.3 模型建立及求解

# 4.3.1 蠕变-过滤效率模型

传统的过滤效率计算公式中涉及到较多物理量，其中某几个物理量之间还可能存在函数关系，这也让过滤效率的计算变得非常复杂。而此处，本文只关心布袋过滤效率与布袋孔径之间的关系，因此为了更加直观的得到两者之间的相互关系，本文采用量纲分析原理，通过逐一分析滤料过滤效率与其影响因素的量纲，利用定理和量纲和谐原理得出滤料过滤效率的无量纲表达式，并将之间的关系定量化，进而提出定性判定滤料过滤效率的新的无量纲物理量。

# a．量纲齐次原理

有物理意义的代数表达式或完整的物理方程式是因次和谐的，或者说齐次的，即方程两边的量纲完全相同，这称为量纲齐次原理。如果一个方程因次上其次，则方程的形式不随基本度量单位的改变而变化。

如果变量与其相关的物理量之间存在物理方程式，  $\mathrm{X} = \prod A^d B^b C^c D^d$  ，其中为无量纲常数，a，b，c，d为量纲指数)，由量纲齐次原理可以确定量纲指数，此外由试验数据、理论规律或其他方法确定常数，则变量与其自变量之间的物理方程式即可建立。

\left\{ \begin{array}{l}a_{1} = 0\\ a_{2} = 0\\ a_{3} = 0 \end{array} \right.
$$

同理, 依据 (4.6) (4.7) (4.8) 的量纲表达式列出方程组, 解得

$$
\left\{ \begin{array}{l}b_{1} = -1 \\ b_{2} = 0 \\ b_{3} = 0 \end{array} \right.
$$

$$
\left\{ \begin{array}{l}c_{1} = -1 \\ c_{2} = 0 \\ c_{3} = 0 \end{array} \right.
$$

联立上述四个方程组的解可以得到:

$$
\left\{ \begin{array}{l}\Pi_{1} = \eta \\ \Pi_{2} = \frac{d_{p}}{d_{f}} \\ \Pi_{3} = \frac{H}{d_{f}} \\ \Pi_{4} = d_{f}w^{-1}\rho \end{array} \right.
$$

即

$$
\eta = \Phi \left(\frac{d_{p}}{d_{f}}, \frac{H}{d_{f}}, d_{f}w^{-1}\rho\right) \tag{4.10}
$$

而填充率  $\alpha = \frac{w}{H\rho}$  是  $\Pi_{1}$  与  $\Pi_{4}$  乘积的倒数, 故 (6) 式可进一步转化为

$$
\eta = \Phi \left(\frac{d_{p}}{d_{f}}, \alpha\right) \tag{4.11}
$$

由上述分析, 本文得到的结论是过滤效率可以有两个无量纲量来判定, 分别是填充率  $\alpha$ , 以及一个新的物理量  $\frac{d_{p}}{d_{f}}$ 。后一个无量纲量表示的是颗粒物直径和滤袋孔径之间的相对大小, 本文用相对尺度来表示这个新的物理量。

$$
\frac{\sigma}{2} = E_{1}\sigma_{1} + E_{2}\sigma_{2} + j\epsilon_{2}^{\prime} \tag{4.12}
$$

其中  $E_{1}$ ,  $E_{2}$  分别表示两弹簧的杨氏模量,  $\mathrm{j}$  表示粘滞系数,  $\epsilon_{1}$ ,  $\epsilon_{2}$  分别表示两部分的应变量,  $\sigma$  表示应力。因为总应变应该等于各部分的应变和,故有下式:

$$
\begin{array}{r}{\epsilon = \epsilon_{1} + \epsilon_{2} = \frac{\sigma}{2E_{1}} +\epsilon_{2}} \end{array} \tag{4.13}
$$

将(4.13)式两端对  $\mathrm{t}$  求导,再与(1)联立消去  $\epsilon_{2}$ ,  $\epsilon_{2}^{\prime}$  得到下述方程:

$$
\frac{E_{1} + E_{2}}{E_{1}E_{2}}\sigma + \frac{j\sigma^{\prime}}{2E_{1}E_{2}} = \epsilon + \frac{j}{E_{2}}\epsilon^{\prime} \tag{4.14}
$$

在布袋除尘器中,因为风速基本保持恒定,滤袋在除尘器中所受到的应力也可以看成一常量,则  $\sigma = \sigma_{c}$ ,  $\sigma^{\prime} = 0$ 。

则原方程可以转化为下述形式:

$$

$$

$$

$$

其中  $\begin{array}{r}{\tau = \frac{j}{E_{2}}} \end{array}$

# 5.2.1温度对气体扩散的影响

# a．扩散效应：

由于空气分子的无序碰撞导致粉尘颗粒产生不均衡的位移，所以表现出粉尘微粒的无规则运动。这种尘粒无规则的运动，除了可能产生尘粒之间的凝集外，还有向低浓度区扩散的趋势。由于捕集纤维表面的浓度较低，所以小尘粒向着纤维表面扩散，并与纤维碰撞而被捕集。[19]

# b.环境温度对气体扩散的影响

环境温度对气体扩散的影响主要表现在环境温度的垂直梯度分布，而对于布袋内气体的扩散的作用的影响体现在以下三个方面：

$①$  温度差会引起介质的转移，也就是热扩散效应。温度梯度的方向和烟气密度决定了烟气在布袋内的扩散方向和扩散范围，可能产生的作用是加强扩散或者减弱扩散。 $(2)$  烟气分子的运动速度会随温度的升高而加快，从而起到加强烟气在布袋内的扩散；同理，烟气分子的运动速度会随温度的降低而减慢，进而烟气在布袋内的扩散也减缓了。 $(3)$  微观上，烟气的粘度同时也受温度的影响，所以烟气在布袋内的扩散速度受到影响。[20]

C.  $C_u$  （Cunningham修正系数）定义：

当微粒在流体中移动，为了计算流体作用在微粒上的拽力，本文需要使用了拽力系数。库宁汉修正系数就是对拽力系数的一个修正。

$$
\begin{array}{r}C_u = 1 + \frac{2\lambda}{d}\cdot (A_1 + A_2\cdot e^{\frac{-A_3\cdot d}{\lambda}}) \end{array} \tag{5.1}
$$

式中：

$C_{u}$  一—库宁汉（Cunningham）修正系数；

$\lambda - -$  气体分子平均自由程；

d- - 微粒直径；

系数  $A_{1}$  ，  $A_{2}$  ，  $A_{3}$  由实验确定

经过试验测得，常温常压下在空气中的系数A：

$$
A_{1} = 1.257, A_{2} = 0.400, A_{3} = 0.55
$$

当微粒很小时，周围的流体将不再是连续的。在拽力计算中本文需要利用用库宁汉（Cunningham）修正系数把这种效应考虑进去。在常温常压下的空气中，当微粒直径小于15um时，库宁汉（Cunningham)修正效应就变得显著起来。

当温度升高时，由于扩散机理增强，以及微粒的团聚作用，使得小于1um的细微尘粒的过滤效率有较大的提高。但对中等粒径的尘粒，扩散机理减弱，而惯性沉积略有增强，总的过滤效率略有下降。大于10um的粗尘粒在高温下惯性变化较小，加之，粘性增大，其高温下的分级分离效率变化较小。

根据以上分析，本文利用Tardos.Gutfinger关于单捕集体的扩散沉积捕集比的公式可以得到下式：[21]

$$
E_{D} = f(\epsilon)P_{e}^{-2 / 3} \tag{5.2}
$$

式中：

$\epsilon$  一 颗粒层孔隙率

$E_{D}$  一扩散系数

$$
\begin{array}{r}P_{e} = \frac{3\pi\mu\nu_{0}d_{g}d_{p}}{C_{u}kT} \end{array}
$$

$d_{g}$  一 过滤介质颗粒直径，mm;

$d_{p}$  一 一尘粒直径，mm;

$k$  一—Boltzman常数，  $k = 1.38\times 10^{- 23}J / K$

结合以上Cunningham修正系数的求解，本文经过简化得到以下公式

$$
C_{u} = 1 + K_{n}[1.257 + 0.42\mathrm{exp}(-0.88 / K_{n})] \tag{5.3}
$$

式中  $K_{n} = \frac{2\lambda}{d_{p}}$

$d_{p}$  一 一尘粒直径，  $\mu m$

$\lambda - -$  温度和压力的函数：

$$
\lambda = \frac{2.9685 \times 10^{-5}}{p_0} \cdot \frac{T}{(1 + 110 / T)} \tag{22}
$$

式中:

T——气体绝对温度, K;

$\mathrm{P}_0$ ——绝对压力;

其中绝对压力  $\mathrm{P}$  表示直接作用于容器或物体表面的压力, 需要注意的是, 绝对压力值以绝对真空作为起点。

颗粒层的总捕集效率公式为

$$
\eta = 1 - \mathrm{e}^{-\frac{3}{2} \frac{(1 - \epsilon)}{\epsilon} \frac{L}{dg} E_X} \tag{5.4}
$$

式中:

$\epsilon$ ——颗粒层孔隙率;

$L$ ——颗粒层厚度,  $\mathrm{mm}$ ;

$d_g$ ——过滤介质颗粒直径,  $\mathrm{mm}$ ;

$E_X$ ——部分捕集比;

$E_D$ ——扩散系数;

若考虑扩散沉积, 令  $E_X = E_D$ , 由  $\lambda$  和  $E_D$  可得过滤效率与温度的关系式: [25]

$$

$$

式中:

$\eta_0$ ——常温下的过滤效率,  $\%$

$C_{u_0}$ ——常温下的cunihgnam滑动修正系数;

$T$ ——气体绝对温度, K;

$T_0$ ——常温, K;

而气体的动力粘度和温度之间的关系可表示为

$$
\mu = \mu_0 \left(\frac{T}{T_0}\right)^{2 / 3} \tag{5.6}
$$

则当扩散沉积占主导地位时温度与颗粒层过滤效率的理论关系式是:

$$
\frac{\ln\left(\frac{1}{1 - \eta}\right)}{\ln\left(\frac{1}{1 - \eta_0}\right)} = \left(\frac{C_u}{C_{u_0}}\right)^{0.67} \left(\frac{T}{T_0}\right)^{0.22} \tag{5.7}
$$

式中:

$\eta$ ——除尘效率,  $\%$

Cu——Cuninhgam滑动修正系数；

通过上述计算，对于扩散沉积，温度升高，过滤效率增加。显然，扩散沉积效率还与尘粒的直径、床层孔隙率、过滤介质颗粒尺寸  $d_{g}$  和床层厚度等因素有关。若尘粒尺寸越小，温度升高时，扩散沉积机理增加的幅度越大。

# 5.2.2 温度对惯性碰撞的影响

惯性碰撞是过滤除尘的主要机制之一，一般粒径较大的粉尘主要依靠碰撞效应捕集。当含尘气流接近滤料的纤维时，气流流线围绕捕集纤维迅速拐弯，其中较大的粒子由于惯性力的作用，偏离了流线，继续沿着原来的运动方向前进，同捕集纤维发生碰撞而被捕集。

尘粒能否同捕集纤维发生碰撞主要取决于运动粒子所具有的惯性力的大小，尘粒直径大，尘粒密度大，提高通过滤料的气流流速，纤维直径小，有利提高惯性碰撞捕集效果。

在惯性控制区域，单颗粒收集效率主要由Stokes数决定，由下式可以看出，即

$$
\begin{array}{r}\mathrm{Stk} = \frac{\rho_P\nu_0d_P^2C_u(T)}{18d_g\mu(T)} \end{array} \tag{5.8}
$$

在惯性区，温度的影响取决于  $C_u / \mu$  ，因为  $\mu \propto T^{0.67}$  ，而对于大于  $1\mu m$  的尘粒  $C_u\approx 1$  ，所以Stk数随温度身高而减小。但是对小于  $1\mu m$  的尘粒，由于  $C_u$  的影响，随温度升高，Stk数会反而增加。这一点与上节的扩散机理分析相吻合。若 $E_{X}\approx \mathrm{Stk}$  ，那么由（3）可以类似得到

$$
\frac{\ln(\frac{1}{1 - \eta})}{\ln(\frac{1}{1 - \eta_0})} = (\frac{Cu}{Cu_0})(\frac{T_0}{T})^{0.67} \tag{5.9}
$$

# 5.2.3 温度对直接拦截的影响

直接拦截是由尘粒和介质颗粒的尺寸决定，即参数  $N_{R} = r_{P} / r_{g}$  决定。尽管直接拦截与温度关系不大，但是严格地讲，直接拦截总是伴随着惯性碰撞和扩散沉积。在实际的颗粒层过滤中，过滤介质颗粒直径约比尘粒大  $100^{\sim}1000$  倍。所以，温度对拦截机理的影响是通过惯性碰撞和扩散沉积而作用的。[24]

# 5.2.4温度对静电捕集的影响

静电除尘的目的是捕集粉尘，净化烟气，最主要的关注点是除尘效率。静电除尘的捕集原理是首先利用高压放电使气体电离，待含尘气体进入电场后，粉尘粒子荷电在静电力的作用下向收尘板移动，从而实现粉尘与气体的分离，达到净化烟气的目的。

当静电力存在时，静电力参数  $K_{e}$  要被叠加到其他参数上，  $K_{e}$  可表示为：

$$
\begin{array}{r}K_{e} = \frac{|\vec{F_{e}}^{\prime}|}{3\pi\nu_{0}d_{P}}\frac{c_{u}(T)}{\mu(T)} \end{array} \tag{5.10}
$$

式中：

$F_{e}$  ——库仑力，N； $K_{e}$  ——静电力系数； $d_{p}$  ——尘粒直径，mm； $T_{0}$  ——气体绝对温度，K；

假定尘粒和收集颗粒的电荷不受温度影响，于是 Coulomb 力保持温度的独立性。然而，由于电极相互作用的存在，那么温度的相关性取决于尘粒和收集颗粒的电极化系数。

# 5.2.5温度对尘粒粘性的影响

研究尘粒与收集颗粒表面的质量传输机理时，温度会产生较大的影响。室温下的分级分离效率测量说明大于  $1\mu m$  的尘粒受高表面过滤速度的影响  $(\nu_{0} > 0.5\mathrm{m / s})$  。可以从室温下颗粒层过滤的分级分离效率测量中清楚地看到：存在一个临界表观过滤速度，当尘粒的速度大于这个速度时，会被反弹；而尘粒速度小于这个速度时，会被粘附。假定碰撞点上有塑性变形，而粘性项从范德华力可得出，于是有临界速度关系式[25]

$$
\begin{array}{r}\nu_{e} = \frac{1}{d_{P}}\frac{(1 - k_{p1}^{2})}{k_{p1}^{2}}\cdot \frac{A}{\pi Z_{0}^{2}(6\rho_{P1}\rho_{P})^{1 / 2}} \end{array} \tag{5.11}
$$

$$
\begin{array}{r}k_{p1}^{2} = \frac{E_{k1} - E_{p1}}{E_{k1}} \end{array} \tag{5.12}
$$

式中：

$\nu_{e}$  ——尘粒的临界弹性碰撞速度，  $\mathrm{m / s}$

$d_{p}$  ——尘粒直径，mm； $k_{p1}$  ——弹性碰撞系数； $Z_{0}$  ——最小接触距离，mm； $\rho_{P}$  ——尘粒密度， $\mathrm{kg} / \mathrm{m}^3$ ； $E_{k1}$  ——惯性分离捕集比； $E_{p1}$  ——塑性变形能量，J；

随温度升高，塑性产生的应力减小，而塑性变形能量  $E_{p1}$  却增加。因此，尘粒的粘性随温度的提高而提高，这对于较高温度下的过滤有好处。

# 5.3 模型建立及求解（温度对过滤效率的综合影响）

上面分析了可能会因温度变化而对过滤效率产生影响的各因素及其机理。但在实际过滤过程中，对过滤效率的影响往往是这些因素的综合作用。在没有外电场作用的情况下，静电捕集作用产生的影响可以忽略不计，而在温度变化不大的情况下，温度对尘粒黏性的影响也很小。因此，本文这里主要考虑温度通过影响气体的扩散沉积和惯性碰撞而对除尘效率产生的影响。

考虑到上述两种因素的相互影响很小，运用穿透率相乘原理，通过计算可以得出如下公式

$$

将（10）式经过简化可以得到：

$$

# a. 设计原因

$①$  除尘器设计：a. 气流不均匀，使得靠近进风口处的舱室内布袋损坏加快（局部射流对滤袋的磨损）b. 滤袋间隔过小

$(2)$  布袋设计：滤袋水解性差，在高温水分S0x存在下很快水解损坏b. 滤袋堵塞

$①$  过滤速度大大超出设计值，滤袋处理的烟气量过大，清灰不及时；

$(2)$  粉尘过细渗入滤袋纤维内部，发生滤袋堵塞；

$(3)$  滤袋过滤粘性大的粉尘时，粉尘在滤袋表面粘连、聚集堵塞滤袋；

$(4)$  由于设备密封不严、漏风、进风管破损、保温效果不佳等原因造成空气进入除尘器或除尘器在低于酸露点温度以下工作，均会造成滤袋糊袋和板结堵塞滤袋并致其破损。[3]c. 化学腐蚀

$①$  被氧化性气体氧化（NO2、SO2、SO3、02等，在高温下会对高分子纤维滤料造成氧化腐蚀）、烟气含氧量

$(2)$  酸结露腐蚀（高温作用下，NO2易结露生成浓硝酸，气体酸结露产生混酸，不仅对滤袋常用的滤料造成氧化，亦会使其发生磺化和硝化反应，是的滤袋在氧化和酸化的协同作用下大面积腐蚀，且强度下降）、

d. 高温损伤

$①$  烟尘中的高温颗粒造成滤袋的灼伤或高温烤灼。进入除尘器的烟气温度不均匀，含尘（特别是大颗粒灰尘较多），超过入口含尘浓度。大颗粒灰尘温度远远超过滤袋规定最高温度，粘附在滤袋上后对滤袋进行局部灼烧、腐蚀

$(2)$  火星随烟气进入除尘器讲滤袋表面灼烧成孔

滤袋失效的主要原因是滤布在外力的长期作用下，滤布纤维发生疲劳蠕变引起的具有一定规律性，而蠕变对除尘效率的影响本文在模型一中已详细讨论。因除尘器结露引起的滤袋堵塞以及因温度过高引起的滤袋烧毁都是在除尘器内部运行条件或外部环境条件出现突变的情况下发生的，具有一定的特殊性。布袋破损受温度、压差、含湿量等因素共同影响，而压降高时布袋破损加快，这时需要

进行清灰处理。当清灰处理后压降依然维持在较高水平时，则需要进行布袋更换。上述导致布袋破损现象出现的因素，除压降外均可视为随机因素，下面本文针对随机因素的出现对布袋破损率的影响进行建立模型。

# 6.3.1 布袋破损数量与时间的关系

# 6.5袋式除尘系统稳定性模型

本文将袋式除尘系统的稳定性定义为其一年内在正常工作状态下除尘效率

的变异系数（标准差/平均值），用以衡量各观测值变异程度的一个统计量同时消除单位和平均数不同对两个或多个变异程度比较的影响。

袋式除尘系统稳定性模型由三个子模型构成，除尘效率持续影响机理模型、温度- 除尘效率直接影响模型和布袋破损间接影响除尘效率模型。

在除尘效率持续影响机理模型中，得到除尘效率- 时间函数为

$$
\eta = \left(1 + \frac{7.5625 - 2.0625e^{-0.014t}}{100}\right)^{-0.1092}(1 - t\times 0.02\%)^{0.5532}\eta_0 \tag{6.6}
$$

表明随着袋式除尘器工作时间的增加，除尘效率会逐步平稳降低，但降低幅度较小，对整体除尘效果影响不大。

在温度- 除尘效率直接影响模型中，不考虑布袋理化性质等对除尘效率造成影响，分别考虑温度因素对过滤过程中气体扩散沉积、惯性碰撞两部分的影响，得到温度直接影响除尘效率的公式

$$
\eta = 1 - (1 - \eta_0)^{(6.2631)^{1.67}\left(\frac{T_0}{T}\right)^{0.446}} \tag{6.7}
$$

在布袋破损间接影响除尘效率模型中，假设输入端的平均烟温、压强、含湿量等会对袋式除尘器除尘效率产生影响的因素保持不变且不考虑其蠕变、磨损等情况时，输出量只与布袋破损有关，由仿生学原理得到布袋破损率和除尘效率满足  $\Delta \eta = \frac{0.6}{1 + e^{- 3.753x + 4.341}}$ ，其中  $\Delta \eta$  为除尘效率的提升量， $x$  为布袋破率。

# 7.3 模型建立及求解

# 7.3.1 高斯扩散模型

对于袋式除尘器排放烟气的情况，本文可以将其排放的烟气看作是一连续的高架气体点源。

为了建立高斯扩散模型，本文先对垃圾焚烧厂周边的状况作出以下假设：风的流场稳定，风速均匀，风向沿x轴方向；污染物浓度在y轴及z轴符合正态分布；烟气在气体扩散过程中质量守恒；气体点源的源强均匀、连续。

本文首先分析地面点源的高斯扩散模型。设其有效源位于坐标原点，且其周围没有任何障碍物影响其扩散。那么大气中的扩散是具有y和z两个坐标方向的二维正态分布，当两坐标方向的随机变量相互独立时，分布密度为每个坐标方向以为正太分布密度函数的乘积。这里，本文取  $\mu = 0$  ，则在点源下任一点的浓度函数为：

$$
\mathrm{C(x,y,z) = A(x)e^{[-\frac{1}{2} (\frac{y^2}{\sigma y^2} + \frac{z^2}{\sigma z^2})]}} \tag{7.1}
$$

式中，A(x)为待定函数， $\sigma_{y}$ ， $\sigma_{z}$  表示气体在y轴及z轴方向上的扩散系数他们与大气稳定度以及水平距离x有关，并且随着x的增大而增大。

由于气体扩散过程中保持质量守恒，在任一垂直于x轴的烟流截面上有：

$$
\begin{array}{r}{\mathbf{q} = \int_{-\infty}^{\infty}\int_{-\infty}^{\infty}u C d y d z} \end{array} \tag{7.2}
$$

式中，q表示源强，即单位时间内排放的污染物总量，u表示风速。

将（7.2）式代入（7.1）式得，A(x)与y，z无关。由于  $\int_{- \infty}^{\infty}e^{- \frac{t^{2}}{2}} = \sqrt{2\pi}$  本文通过积分可以得到待定函数：

$$
\begin{array}{r}{\mathrm{A}(\mathrm{x}) = \frac{q}{2\pi u\sigma_{y}\sigma_{z}}} \end{array} \tag{7.3}
$$

再代入（7.1）式可以得到：

$$
\begin{array}{r}{\mathrm{C}(\mathrm{x},\mathrm{~y},\mathrm{~z}) = \frac{q}{2\pi u\sigma_{y}\sigma_{z}} e^{[-\frac{1}{2}\left(\frac{y^{2}}{\sigma_{y}^{2}} +\frac{z^{2}}{\sigma_{z}^{2}}\right)]}} \end{array} \tag{7.4}
$$

下面本文把气体点源在地面上的投影取作坐标原点，那么气体点源位于z轴上。高架有效点源的高度有两部分组成，即  $\mathrm{H} = \mathrm{h} + \Delta \mathrm{h}$ ，其中h表示排放口的有效高度， $\Delta \mathrm{h}$  是热烟流的浮升力和烟气以一定速度竖直离开排放口的冲力使烟流提升的一个附加高度。

当污染物到达地面后，本文认为污染物全部被地面反射。那么，本文可以利用全反射原理，通过像源法求解空间中任意一点的浓度。那么高架点源通过扩散在空间中一点的实际浓度就是实点源与和其关于地面对称的虚点源浓度的叠加。根据地面点源扩散的公式，本文有：

$$
\begin{array}{r}{\mathrm{C}(\mathrm{x},\mathrm{~y},\mathrm{~z}) = \frac{q}{2\pi u\sigma_{y}\sigma_{z}} e^{[-\frac{1}{2}\left(\frac{y^{2}}{\sigma_{y}^{2}} +\frac{z^{2}}{\sigma_{z}^{2}}\right) ]}} \end{array} \tag{7.4}
$$

式中， $\sigma_{y}$ ， $\sigma_{z}$  表示气体在y轴及z轴方向上的扩散系数，q表示源强，即单位时间内排放的污染物总量，u表示风速。他们与大气稳定度以及水平距离x有关，并且随着x的增大而增大。但是需要注意的是，此处的坐标原点就是气体点源。

空间中任意一点k，在以实源为原点的坐标系中的垂直坐标为(z- H)，则实点源在k点扩散的浓度为下式：

$$
\begin{array}{r}\mathbf{C}(\mathbf{k}) = \frac{q}{2\pi u\sigma_y\sigma_z} e^{[-\frac{1}{2}\left(\frac{y^2}{\sigma_y^2} +\frac{(z - H)^2}{\sigma_z^2}\right)]} \end{array} \tag{7.5}
$$

而  $\mathrm{k}$  点在以虚点源为原点的坐标系中，垂直坐标为  $(z + \mathrm{H})$  ，则虚点源在  $\mathrm{k}$  点扩散的浓度为下式：

$$
\begin{array}{r}\mathbf{C}(\mathbf{k}) = \frac{q}{2\pi u\sigma_y\sigma_z} e^{[-\frac{1}{2}\left(\frac{y^2}{\sigma_y^2} +\frac{(z + H)^2}{\sigma_z^2}\right)]} \end{array} \tag{7.6}
$$

由此可得  $\mathrm{k}$  点处实际污染物的浓度为：

$$
\begin{array}{r}\mathbf{C}(\mathbf{k}) = \frac{q}{2\pi u\sigma_y\sigma_z} e^{\frac{-y^2}{2\sigma_y^2}}e^{-(\frac{(z - H)^2}{\sigma_z^2} +\frac{(z + H)^2}{\sigma_z^2})}] \end{array} \tag{7.7}
$$

考虑到袋式除尘器的实际情况，本文此处最关心的是烟囱作为高架点源在地面处污染物浓度的分布情况，对上式，本文取  $\mathrm{z} = 0$  得到

$$
\begin{array}{r}\mathbf{C}(\mathbf{x},\mathbf{y},0) = \frac{q}{2\pi u\sigma_y\sigma_z} e^{-\frac{1}{2} (\frac{y^2}{\sigma_y^2} +\frac{H^2}{\sigma_z^2})} \end{array} \tag{7.8}
$$

进一步，令  $\mathrm{y} = 0$  ，本文可以得到污染物浓度沿  $\mathbf{X}$  轴方向的浓度分布：

$$
\begin{array}{r}\mathbf{C}(\mathbf{x},0,0) = \frac{q}{2\pi u\sigma_y\sigma_z} e^{-\frac{H^2}{2\sigma_y^2}} \end{array} \tag{7.9}
$$

并且在  $\mathrm{y}$  轴方向上，污染物浓度以  $\mathbf{X}$  轴为对称轴呈现正态分布。

# 7.3.2高斯扩散模型的修正

通过上述分析，本文得到了理论上空间中任意一点污染物的浓度。但是在实际应用中，高斯扩散模型往往因为以下原因而存在一些误差：

（1） 用环境风速代表了气体的水平输送速度。

（2） 在计算h时，没有考虑高度对风速的影响。

因为以上两点原因，直接运用高斯扩散模型得到的污染物浓度往往与实际值存在一定误差，因此该部分本文通过对风速的修正以得到更为精确的扩散模型。[26]

# a.  $\Delta \mathrm{h}$  的推导

$\Delta \mathrm{h}$  的计算通常有两种方法，一种是通过提升机理的分析得到理论公式，一类是通过实地观测得到的经验数据。本文这里选取我国环境影响评价导则所推荐的半经验公式

$$
\begin{array}{r}\mathrm{H} = \mathrm{h} + \Delta \mathrm{h} = \frac{R}{u_e} \end{array} \tag{7.10}
$$

式中R为抬升参量，与烟体的动力和热力条件有关；

$u_{e}$  为烟气抬升层内的平均风速，即：

$$
\begin{array}{r}u_{e} = \frac{1}{\Delta h}\int_{\mathrm{h}}^{\mathrm{h} + \Delta \mathrm{h}}U_{(z)}dz \end{array} \tag{7.11}
$$

因为环境风速随高度增加呈指数型增长，本文可以用下式表示：

$$
\begin{array}{r}u_{(z)} = u_0\left(\frac{z}{z_0}\right)^{P'} \end{array} \tag{7.12}
$$

其中  $u_{(z)}$ ， $u_{0}$  分别表示高度为  $z$  米及高度为10米处的风速，P'为风速高度参数，与大气稳定度有关，其函数可以通过环境影响评价导则得到。

通过上述三式，本文可以得到抬升公式为：

$$
\begin{array}{r}\Delta \mathrm{h} = \left[h^{p' + 1} + \frac{WA}{u_0}\right]^{\frac{1}{p' + 1}} - h \end{array} \tag{7.13}
$$

抬升层平均风速为：

$$
\begin{array}{r}u_{e} = \frac{W}{\Delta h} = \frac{W}{[h^{p' + 1} + \frac{WA}{u_{0}}]^{\frac{1}{p' + 1}} - h} \end{array} \tag{7.14}
$$

其中A为风速垂直变化参数（  $\mathrm{A} = (\mathrm{P}^{\prime} + 1)\times 10^{P}$  )。由此本文就得到了有效高度的修正公式。

# b.u的确定

在高斯扩散模型中，u反映的是污染物水平输送的平均速度。因此，如果直接把环境风速作为常量代入，本文就忽略了高度对于风速的影响。所以此处，u应是污染物扩散层的平均风速，即：

$$
\begin{array}{r}\mathbf{u} = \frac{1}{H}\int_{0}^{H}u(z)dz \end{array} \tag{7.15}
$$

将（3）式代入积分可得

$$
\begin{array}{r}\mathbf{u} = \frac{u_0}{A} H^P = \frac{u_0}{A} [h^{P + 1} + WA]^{\frac{P}{P + 1}} \end{array} \tag{7.16}
$$

# 7.4.2除尘效率波动对技术敏感性

根据之前的分析，在正常工况与非正常工况下，一个最为明显的指标就是袋式除尘器运行过程中受到的阻力。当阻力增大，袋式除尘器的能量利用率降低，布袋破损数量及磨损程度也会相应增加进而导致除尘效率降低。因此我们将除尘效率波动对袋式除尘器技术指标的敏感性归结为除尘效率对压强的敏感性，即  $\frac{\Delta\eta}{\Delta p}$ 。

通过之前的分析，阻力主要通过影响布袋破损数量及比例影响除尘效率，而在布袋破损的部分，我们已经得到了压强、时间与破损布袋比例之间的关系为：

# 7.4.3除尘效率的提升限度

7.4.3 除尘效率的提升限度根据之前得到的结论，在正常运行的情况下，除尘效率是一个随时间递减的函数，并且主要受到温度、布袋破损、蠕变及磨损的影响。其中烟温是相对可控的，而对于布袋的破损、蠕变及磨损则只能通过增加更换布袋的频率来解决。而根据之前进行的敏感性分析，除尘效率与布袋破损个数之间的敏感性也是非常之高，因此这一部分本文重点研究在运行成本允许的前提下，布袋的更换频率至多可以增加到什么程度，进而提高除尘效率。

# a.垃圾烧厂的运营成本及盈利模式

对于垃圾烧厂而言，其盈利模式主要由两方面构成，一部分是政府的补贴政策，即垃圾烧厂每处理1吨垃圾，政府会给予  $70^{\sim}120$  元的补助，在珠三角地区资助一般为100元/吨。另一部分主要来源于在烧垃圾的过程中，垃圾烧厂可将其过程中产生的多余电量用来出售，其售价约为0.65元/度，而每烧1吨垃圾平均可以产生280度电，因此发电对于垃圾烧厂而言也是非常可观的一笔收益。

而垃圾烧厂的日常主要花费由设备的购买以及折旧、相关工作人员的工资等开销，以及日常运营过程中设备的维护构成。这里我们以一日处理量为1000吨的垃圾烧厂为例分析其运营成本。

一套日处理量达到1000吨，且可满足垃圾烧厂日常运营需求的设备的购买价格为  $3^{\sim}4$  亿元，这里我们取为4亿，其年折旧率约为设备价格的  $6\%$  ，我们按2400万元计算。而为了运营一日处理量达到1000吨的垃圾烧厂，需要员工约150人，每年的工资发放需要约1000万，加上办公费、水电费以及其他配件材料的消耗费用（如活性炭的消耗、废料的填埋等），我们认为其日常运营成本为每年2400万元。剩下的其他费用均可花费在设备维护上。

考虑到一垃圾烧场需要在  $8^{\sim}12$  年内实现盈利，我们由此推断出其每年运行成本的最大上限。在这里，我们假设一垃圾烧厂10年内需要完成盈利  $20\%$  那么10年后原设备折损了2.4亿的价值，则平均每年需要保证盈利3200万元才能达到盈利要求。依照平均运营时间，除尘设备在一年中运行8000小时（  $90\%$

负荷），那么可以处理垃圾33.3万吨，因此获得政府补贴3300万元，与此同时依靠这些垃圾发电获利6000万元。

按此估计，袋式除尘器每年至多有1300万元的预算可以用于设备维护，且随着使用年限的增长设备维护费用会逐渐增加，因此我们假设实际生产过程中只有1000万元可以投入到日常的维护工作中。因为大约需要2个燃烧炉才可能达到1000吨的日处理量，分摊到各燃烧炉中其维护费用的预算为500万元。

在这500万元中，按照规定，每年必须进行一次设备大修以保证除尘器的持续正常运行，这项工作每次需要花费约300万元。因此用于更换布袋的费用至多还有200万剩余。以一个袋式除尘器含有1000个布袋，每个布袋价值450元计算，每次全部更换需要花费45万元。考虑到在正常运行过程中也会有布袋因为糊袋、高温损坏等原因造成的布袋破损，一年中至多进行3次布袋的整体更换。而如果按照这个频率，在更换时还依然有相当大一部分滤袋处于较为良好的状态，只是因为磨损无法继续保持较高的除尘效率，因此垃圾焚烧厂完全可以利用这些材料进行其他的处理以获得额外的收入。

综上所述，通过分析垃圾焚烧厂的成本及收益情况，我们发现布袋的更换频率至多为一年三次。

# b.除尘效率的提升

在一年更换三次布袋的情况下，平均每4个月（约120天）就会全部更新。而每次更换布袋后就可以完全避免因为磨损或蠕变造成的除尘效率下降。因此，根据我们之前得到的除尘效率函数，在新的更换布袋的频率下，袋式除尘器的除尘效率可以保证在  $97.5\%$  以上。该除尘效率与之前年末只有  $95\%$  的除尘效率相比有了显著的提升。

# 7.4.4最大扩建上限

根据上述分析，我们已经得到了颗粒物排放浓度的限制条件，以及采取新的更换布袋方案后除尘效率的提升。现在我们利用之前得到的对袋式除尘器稳定性的分析，来求垃圾焚烧厂的最大扩建上限。

根据袋式除尘系统稳定性的分析，我们知道袋式除尘器的除尘效率随时间及温度变化的函数是

$$

$$
\frac{0.6}{100(1 + e^{-0.01748\mathfrak{t} + 4.341})} (1 - (0.1)^{\left(\frac{Cu}{Cu_0}\right)^{1.6}\left(\frac{T_0}{T}\right)^{0.446}}) \tag{7.28}
$$

在这里，因为炉温变化在一个相对较小的范围内，我们取定  $\mathrm{T} = 220^{\circ}\mathrm{C} = 493\mathrm{K}$ 。

因为最后的排放浓度是有烟囱出口的颗粒物浓度确定。根据袋式除尘器运行过程中的相关数据，我们得到烟囱的平均排放浓度为  $8.13\mathrm{mg} / \mathrm{m}^3$ ，那么根据之前的除尘效率随时间变化的函数，我们通过对  $\eta$  进行积分  $\frac{\int_{0}^{365}mdt}{365}$  得到袋式除尘器在一年的时间里正常运行过程中的平均除尘效率为  $97.1\%$ ，那么我们认为，袋式除尘器目前的处理垃圾量即为相对于烟囱出口的  $271.9\mathrm{mg} / \mathrm{m}^3$

为了避免随机因素对除尘效率的干扰是的除尘效率在某一时间段内降低，导致排放烟尘浓度超标，我们根据垃圾焚烧厂普遍的标准，将理论排放浓度控制在限定值的  $65\%$  以下。因为在更换布袋前，袋式除尘器的最低除尘效率为  $97.5\%$ ，那么我们就可以利用相关数据计算出在排放达标的情况下，袋式除尘器的最大扩建规模。

当  $\frac{\lambda}{2.59} \geq 20$  时，颗粒物浓度的限制条件是  $C \leq 20$ ，为了保证在最低除尘效率的时间点排放浓度不超过标准的  $65\%$ ，处理垃圾量相对于烟囱的除尘浓度为  $520\mathrm{mg} / \mathrm{m}^3$ ，即垃圾焚烧厂可以扩建到原先的 1.91 倍。

当  $\frac{\lambda}{2.59} \leq 20$ ，颗粒物浓度的限制条件是  $C \leq \frac{\lambda}{2.59}$ ，同理，为了保证在最低除尘效率的时间点排放浓度不超过标准的  $65\%$ ，处理垃圾量相对于烟囱的除尘浓度为  $\frac{2600\lambda}{259}\mathrm{mg} / \mathrm{m}^3$ ，即垃圾焚烧厂扩大为原来的  $\frac{\lambda}{26.99}$  倍。

垃圾焚烧发电工程是事关周边区域可持续发展的重要环保工程，同时也是广大群众高度关注的民生工程，关系到人民群众的生命健康。因此，本文依据模型求解结果，给政府相关部门提出如下建议，从而推进周边环境保护与治理工作，最大限度地减少或避免因工厂运作引发的环境问题并逐步治理之，实现社会经济

的可持续发展：

1. 政府应对焚烧厂采用多指标、多维度的环保综合监控系统来进行监测，对垃圾焚烧厂的废气废水的排放情况、环境安全参数(温度、压力、气体浓度等)、环境污染参数(二噁英等大气排放物浓度)进行同步实时检测和监控，一旦发现所监控的污染源超标，立刻采取一系列的报警联动机制，使得其周边环境状况得到最大程度的保障。另外采用先进的网络技术，使得垃圾焚烧厂与上级安监、环保部门间实现真正意义上的数字化集成监测和预警，从而有效地预防重大安全和环境污染事故的发生。环保部门除了应重点在垃圾焚烧厂自身的袋式除尘器设置大气排放物检测点外，还应在在其周边3公里的土壤表层设置检测点来监测污染物进入土壤的情况。

2. 对焚烧厂所产生的固体废物，应设置专用场所堆放并使用专业垃圾运输车进行垃圾运输，并采取有效措施防止二次环境污染及诱发次生地质灾害。政府应根据固体废弃物的性质、贮存场所的工程地质情况，采用完善的防渗、集排水措施，防止淋溶水污染地表水和地下水；对存放含有有毒、有害物质的废气、废液的淋浸池、贮存池、沉淀池必须制定防水、防渗漏、防流失等措施。同时，政府应效仿国外成熟的废物垃圾运输准则，采购负压运输车进行垃圾运输并加强对运输过程的监管，减少垃圾运输对沿途群众的生活影响。

3. 鉴于布袋除尘器对环境的污染方式主要是大气污染，除尘效率将成为环境保护的关键因素，政府应采取技术补贴手段鼓励厂家加大研发投入来研发较高温度下运转的袋式除尘器来将除尘效率保持在一个较高水准。

4. 对于现存垃圾处理厂，环保部门应经常对垃圾处理厂的袋式除尘器的破损情况进行抽查，确保一年中布袋破损运转的天数严格低于环保标准规定的天数并对抽查不合格的垃圾处理厂采取警告、罚款甚至关停的处罚措施。

5. 对于未来将要建设的垃圾处理场，政府要对其选址工作提供专业、合理的建议，另外严格规定新建垃圾处理厂的最大扩建规模不得超过原先的  $\frac{\lambda}{26.99}$  倍，其中  $\lambda$  为单位面积排放总量限额（地区总量/地区面积）。

在此理论分析的基础上，本文考虑到袋式除尘器运行过程中还有其他各种因素会对除尘效率产生影响，在前文研究中为了方便研究，本文做出了基本假设来忽略这些因素的影响，这部分将放松假设，把其他各种非主要的影响因素看作一个随机影响因素进行考虑，加入到原除尘效率随时间变化函数之中。

由于各种因素影响微小且相对独立，本文假设该随机因素的增长率满足一个广义维纳过程

$$
dr(t) = r(t)\mu \mathrm{dt} + r(t)\sigma \mathrm{dB}_t \tag{7.29}
$$

其中  $B_{t}$  表示布朗运动，即白噪声；  $\mu$  表示漂移率（即波动的平均增长量），  $\sigma$  表示波动的方差。对于除尘效率的波动情况，方差则根据除尘效率的预测函数与实际值的残差得出，这里本文取为1.13。对于上述随机微分方程，本文利用伊藤

积分解得：

$$
r(t) = r_0 \times e^{\left(\mu - \frac{1}{2} \sigma^2\right)t} + \sigma B_t \tag{7.30}
$$

对于新型超净除尘工艺，因为其采用固体滤料，很多造成袋式除尘器过滤效率下降的因素都可以避免。

根据袋式除尘器稳定性的模型，袋式除尘器的除尘效率主要受到温度、蠕变、磨损以及布袋破损的影响。而对于固体滤料而言，布袋破损的情况不会出现，固体磨损对其总质量产生的影响也可以忽略不计，而固体滤料的抗蠕变性能也远远好于布袋，在一年的时间周期内，蠕变对于其滤料孔径产生的影响也十分微小。综合以上分析，其固体滤料除尘效率产生影响的因素主要只有温度。因为温度可

以较为容易的通过相关技术进行控制，在实际运行过程中温度只会在较小的范围内波动，本文将温度取为一定值代入原除尘效率的函数即可。

综上所述，本文可以认为新型超净除尘工艺的除尘效率在较长时间内是几乎保持稳定的，其波动只受不可控的随机因素的影响。

# 8优点与不足

# 8.1优点

8.1 优点(1) 考虑因素相对全面，袋式除尘系统稳定性模型构建较为合理。(2) 从计算动力学出发设计模型，很好的刻画了袋式除尘器的工作机理。(3) 预测模型引入随机因素，考虑全面，预测结果与实际值较为贴合。(4) 模型三运用仿生学原理，数据拟合程度高，模型解释力高。

# 8.2缺点

8.2 缺点(1) 在整体假设中规定各变量相互独立的影响除尘效率，尽管是基于理论推导得出的结论，但是没有很好的刻画各变量间的耦合关系。(2) 在经济、技术敏感性分析时，尽管给出的经济、技术指标可以在很大程度上表示其经济效益和技术效能，但是依然有很多细节没有充分考虑，有待进一步完善。

# 9结论

为了实现量化分析袋式除尘器的稳定性并预测垃圾焚烧厂的最大扩建规模、使用新工艺以后的稳定性能的提升情况的目的，本文首先给出袋式除尘器的稳定性定义，随后依次分析可能会对袋式除尘系统除尘效率产生影响的各因素从而得到袋式除尘器在正常运行状态下除尘效率随时间的变化情况，最后利用实际数据进行拟合，验证上述除尘效率随时间变化曲线的合理性，并对其运行稳定性作出评价。主要得出以下结论：

1. 在假定只考虑布袋蠕变、磨损两因素对除尘效率的持续影响时，得到除尘效率-时间函数为  $\eta = \left(1 + \frac{7.5625 - 2.0625\mathrm{e}^{-0.014t}}{100}\right)^{-0.1092}(1 - t\times 0.02\%)^{0.5532}\eta_0$  ，表明

随着袋式除尘器工作时间的增加，除尘效率会逐步平稳降低，但降低幅度较小，对整体除尘效果影响不大。

2. 在不考虑布袋理化性质对除尘效率造成影响的情况下，分别考虑温度因素对过滤过程中气体扩散沉积、惯性碰撞两部分的影响，得到温度直接影响除尘效率的公式  $\eta = 1 - (1 - \eta_0)^{(6.2631)^{1.67}}\left(\frac{\mathrm{T}_0}{\mathrm{T}}\right)^{0.446}$  。上述公式表明，温度升高  $50^{\circ}\mathrm{C}$ ，袋式除尘器的除尘效率大约降低  $0.1\%$ ，这对整体除尘效果影响并不明显，但这是未来袋式除尘器改进的潜在方向之一。

3. 假设输入端的平均烟温、压强、含湿量等会对袋式除尘器除尘效率产生影响的因素保持不变且不考虑其蠕变、磨损等情况时，输出量只与布袋破损有关，由仿生学原理得到布袋破损率和除尘效率满足  $y = \frac{0.6}{1 + e^{-3.753e + 4.341}}$ ，其中  $y$  为除尘效率的提升量，  $x$  为布袋破率。与前述持续影响和直接影响的效果相比，布袋破损对除尘效率的影响是较为明显的，短期内可能出现除尘效率跃变式下滑，对环境造成严重且不可逆的污染，应当受到相关监管部门和垃圾处理厂的重视。

4. 依据相关规定给出的限制排出烟气浓度条件和本文给出模型的测算结果，本文给出袋式除尘器可以承受的最大垃圾处理量，从而得到理论上的垃圾焚烧厂的最大扩建规模不应超过原先的  $\frac{\lambda}{26.99}$  倍，  $\lambda$  为单位面积排放总量限额（地区总量/地区面积）。这表明，当垃圾焚烧厂扩建规模过大时，当前技术条件下的袋式除尘器已经无法控制烟尘排放对当地环境造成的污染，将引发一系列生态问题；当垃圾焚烧厂扩建规模不足时，尽管最终排放达标，但是袋式除尘器的除尘效能没有被完全利用起来，造成设备的无效折旧，最终对垃圾焚烧厂产生额外的成本，影响其持续发展的经济效益。
